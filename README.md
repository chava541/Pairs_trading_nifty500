# Cointegration-Based Pair Trading on the NIFTY 500

A research notebook for exploring statistical-arbitrage pair trading in Indian equities. It screens same-industry stock pairs for Engle–Granger cointegration, estimates rolling hedge ratios, generates z-score signals, and evaluates the strategy in separate in-sample (IS) and out-of-sample (OOS) periods.

> **Research/educational use only.** This is not investment advice or a production-ready trading system. The embedded backtest results are not evidence of future profitability.

## Overview

The notebook implements the following pipeline:

1. Load a historical NIFTY 500 constituent list and download adjusted daily prices from Yahoo Finance using `yfinance`.
2. Clean and align the price panel, requiring sufficient history and limiting missing data.
3. Restrict candidate pairs to stocks in the same industry, then run Engle–Granger cointegration tests on log prices during the IS period.
4. Rank significant pairs by cointegration p-value and keep up to 200 pairs.
5. Choose a regression direction and calculate rolling OLS intercepts, hedge ratios, residuals, and residual z-scores using windows of 100, 150, 200, and 252 observations.
6. Backtest mean-reversion entries/exits, a z-score stop, a maximum holding period, approximate beta-neutral sizing, and transaction costs.
7. Compare IS window results, choose a window, and evaluate the frozen selected pair list OOS.
8. Produce equity curves, drawdowns, trade-return distributions, pair diagnostics, a monthly PnL heatmap, and CSV/text reports.

## Setup

### 1. Requirements

Use Python 3.10+ (the notebook was run with pandas 2.2.3, NumPy 1.26.4, and yfinance 0.2.66).

```bash
python -m venv .venv
```

Activate the environment:

- Windows PowerShell: `.venv\Scripts\Activate.ps1`
- macOS/Linux: `source .venv/bin/activate`

Install dependencies:

```bash
pip install -r requirements.txt
```

### 2. Add the constituent CSV

Place the historical constituent file at:

`data/ind_nifty500list_jan_28_2022.csv`

The notebook expects columns named `Symbol` and `Industry` (it also uses company/name metadata for display). The CSV is not included in this repository; add a source file you are permitted to redistribute, or update `Config.UNIVERSE_CSV` to your local path. The universe should represent the intended historical date if you want to reproduce the described experiment.

### 3. Run the notebook

```bash
jupyter lab
```

Open `pair_trading_nifty500.ipynb` and run the cells in order. It downloads prices from Yahoo Finance, so network access and Yahoo Finance availability/rate limits affect reproducibility. The notebook contains the outputs from the saved run; rerunning may produce different data/results.

Generated files are written to `pair_trading_output/`:

- `cointegrated_pairs.csv` — selected pairs and cointegration/regression estimates
- `pair_summary.csv` — per-pair metrics split by IS/OOS
- `trade_log.csv` — trade-level records
- `research_report.txt` — text report

These output files are generated by executing the notebook and are not bundled as raw datasets in this repository.

## Important limitations and checks before using results

- **Survivorship bias:** the report itself flags use of a current/historical list as a limitation. Confirm the exact constituent CSV and point-in-time membership before making historical claims.
- **Multiple testing:** screening thousands of pairs at a nominal 5% p-value threshold creates false positives. Consider adjusted p-values and an additional validation period.
- **Cointegration instability:** only 8.5% of selected pairs are reported as remaining cointegrated OOS in the saved stability test.
- **Weak OOS risk-adjusted results:** the saved report's OOS Sharpe is negative (-0.72), and profit factor is 1.19.
- **Execution realism:** costs are simplified; the model does not fully account for market impact, liquidity, taxes/fees, borrow availability, or securities-lending costs.
- **Shorting constraints:** many Indian equities may not be available to short in the assumed manner.
- **Model assumptions:** rolling OLS hedge ratios, z-score thresholds, and the direction-selection heuristic need additional validation.
- **Sizing/PnL validation:** verify the beta-neutral sizing, leg PnL, return denominator, portfolio aggregation, and annualization conventions independently before relying on performance metrics.
- **Data quality/corporate actions:** results depend on Yahoo Finance data coverage and adjusted-price conventions.
- **Notebook output discrepancies:** the saved outputs show 447 tickers in the cleaned panel but 448 in the surviving-universe count. Investigate this mismatch before treating the results as final.

## Suggested next improvements
